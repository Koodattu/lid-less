A new look, and updates built in

  • A native popover with Liquid Glass controls on macOS 26+, a material fallback, and animated session states.
  • 30-minute, 1-hour, 2-hour, and 8-hour sessions with a live countdown.
  • Preferences for launch at login, Option-close, confirmation sound, and a 10–50% battery cutoff.
  • A quick start, dedicated recovery state, About view, and copyable diagnostics.
  • Signed updates from GitHub Releases through Sparkle, with optional automatic checks. Installation asks first and waits for your session to end.
  • A new app icon and additional lifecycle, preferences, and update tests.

Requires Apple Silicon and macOS 14+. Downloads remain ad-hoc signed, not Apple-notarized. Existing v0.1.x users must install this version manually once to enable future in-app updates.
