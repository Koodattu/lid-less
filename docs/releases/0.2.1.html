Smoother controls, updates in the popover

  • Stable window and session-control positions when arming or canceling; animation stays on the laptop illustration and countdown.
  • A high-contrast primary button that only dims when it is actually disabled.
  • Update checks, download progress, cancellation, errors, and Install & Restart now live inside the popover.
  • Checking for updates and update-available notices no longer block arming. Downloading or installing waits until your session ends.
  • Cancel Arming, End Session, and Retry Restore Sleep always remain available. Canceling an update releases the arming lock without reopening the popover.

Sparkle still verifies the signed feed and archive and handles installation. macOS may present its own authorization prompt when required. Apple Silicon, macOS 14+. Builds remain ad-hoc signed, not Apple-notarized.
